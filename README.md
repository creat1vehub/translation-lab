# Translation Lab — первая версия

Личный адаптивный веб-тренажёр письменного перевода для русского, немецкого и английского языков.

## Уже реализовано
- Все 6 направлений: RU↔DE, RU↔EN, DE↔EN.
- Интерфейс на русском языке.
- Уровни B1, B2, C1, C2.
- Генерация задания ИИ по направлению, уровню, формату и теме.
- Самостоятельный ввод исходного текста и перевода.
- ИИ-разбор на русском: смысл, грамматика, лексика, стиль, варианты и переводческие трансформации.
- Озвучивание исходного текста средствами браузера; текст можно скрыть до прослушивания.
- Архив на устройстве (localStorage), поиск, открытие, удаление и экспорт JSON.
- Адаптивная вёрстка для планшета и телефона.

## Важно
Сейчас это исходный проект, а не уже опубликованный общедоступный сайт. Для работы ИИ нужен сервер и API-ключ. Ключ хранится только на сервере в `.env`, не в браузере. История пока хранится локально в браузере конкретного устройства: она не синхронизируется между устройствами и может исчезнуть при очистке данных браузера. Регулярно экспортируй архив.

## Запуск локально
Требуется Node.js 20 или новее.

```bash
npm install
cp .env.example .env
```

Добавь свой API-ключ в `.env`:
```env
OPENAI_API_KEY=твой_ключ
OPENAI_MODEL=gpt-5.5
PORT=3000
```

Запуск:
```bash
npm start
```
Открой `http://localhost:3000`.

## Публикация в интернете
1. Создай приватный репозиторий GitHub и загрузи файлы проекта.
2. Создай Node Web Service на Render (или другом Node-хостинге), подключи репозиторий.
3. Build command: `npm install`
4. Start command: `npm start`
5. Добавь в настройках сервиса переменные `OPENAI_API_KEY` и `OPENAI_MODEL`.
6. После деплоя хостинг выдаст публичный HTTPS-адрес.

Не публикуй `.env` и никогда не вставляй API-ключ в `public/app.js` или HTML.

## API
Сервер использует OpenAI Responses API (`POST https://api.openai.com/v1/responses`). Модель настраивается переменной `OPENAI_MODEL`. При отсутствии ключа генерация и проверка честно сообщают, что ИИ не подключён; приложение не подменяет реальную проверку фиктивной оценкой.


## Локальный режим без сервера
Если открыть `public/index.html` двойным щелчком, кнопка генерации выдаёт встроенный тренировочный текст для выбранной пары (без ИИ). ИИ-генерация и ИИ-проверка требуют запуска Node.js-сервера и настройки API-ключа. При открытии как локального файла приложение теперь показывает понятное уведомление вместо технической ошибки Failed to fetch.


## Обновление интерфейса
В этой сборке использована более приглушённая пыльно-розово-серая палитра, сохранена исходная компоновка. Размеры основного текста, подписей и полей ввода увеличены для комфортного чтения на планшете.


## Последние исправления интерфейса и аудио
Панель управления аудированием перенесена на отдельную строку под заголовком исходного текста, чтобы элементы не накладывались. При смене скорости или голоса во время воспроизведения озвучивание перезапускается с начала с новыми настройками; если оно было на паузе, пауза сохраняется. Цветовая гамма дополнительно затемнена.


## Новые возможности
Добавлены уровни A1 и A2 с отдельными инструкциями для генерации заданий и проверки переводов. Формулировки интерфейса сделаны нейтральными по роду. Повышен контраст нижнего колонтитула, карточек прогресса и подписей.


## Исправление словаря и полей ввода
Раздел личного словаря и все его элементы теперь присутствуют в HTML-разметке, поэтому обработчики интерфейса подключаются корректно. Поля исходного текста и перевода автоматически увеличивают высоту по мере ввода; ручной маркер изменения размера отключён. При серверной ИИ-генерации список изучаемых слов передаётся в запрос и может использоваться для органичного повторения.


## Автоматические словарные статьи
При добавлении выделенного слова приложение обращается к `/api/lookup`. ИИ возвращает перевод, часть речи, словарную форму, пример и грамматические сведения. Для немецких существительных показываются артикль, род, единственное и множественное число; для немецких глаголов — Infinitiv, Präsens, Präteritum, Partizip II и тип (сильный/слабый/смешанный). Для английских глаголов — основные формы и regular/irregular. Если сервер недоступен, слово всё равно сохраняется, а карточку можно дополнить позднее кнопкой «Найти перевод и формы».
